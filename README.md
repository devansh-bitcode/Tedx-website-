
**Project Description — TEDx Event Website**

*This project is a fully designed and developed website created to showcase and support a TEDx event. The site provides an engaging and user-friendly platform where visitors can explore event details, speaker profiles, schedules, themes, and registration information. It features a clean, modern layout inspired by TED’s visual identity, ensuring a professional and immersive experience.*

*The website highlights key aspects of the event, including featured talks, organizer information, venue details, and updates. Built with responsive design, it delivers smooth navigation across devices and offers an intuitive interface for users to stay informed and connected. This project demonstrates strong skills in web design, front-end development, UI/UX, and event-focused digital presentation.*
